# Старые файлы шаблонов

Каталог `templates/` временно содержит прежний контур сборки шаблона Debian 13.

Новые шаблоны описываются в:

```text
packer/<VMID>/
```

Для `9000` основной источник находится в:

```text
packer/9000/
```

`templates/debian13/` сохранён только до первой успешной реальной Packer-сборки и затем должен быть удалён вместе со старым PVE-side шаблонным контуром.
