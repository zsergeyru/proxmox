# Старый контур шаблона Debian 13

**Статус:** временно сохранён для справки и отката до первой успешной реальной сборки Packer.

Этот каталог описывает прежний способ создания шаблона `9000` из Debian cloud image через PVE-side сценарии.

Он **не является источником новой архитектуры** и не должен использоваться для новых изменений шаблона.

Текущий источник:

```text
packer/9000/
```

Текущая версия нового шаблона:

```text
Template-Version: 8
```

Штатный запуск:

```text
Semaphore
→ Build Template 9000
→ scripts/infra-deployer/build-template.sh 9000
→ Packer
```

Старые файлы этого каталога и модули `scripts/pve/setup/lib/60-63-template-*` будут удалены после успешной реальной сборки и проверки Packer-шаблона на PVE. До этого момента они сохраняются только как диагностический и сравнительный материал.
