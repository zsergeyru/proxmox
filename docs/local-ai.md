# Локальный AI и inference

Документ отделяет эксперименты с локальными моделями от эксплуатационной документации VM `ai-control`.

## Текущая inference-платформа

- GPU-компьютер: RTX 5060 Ti 16 GB.
- Основной OpenAI-compatible inference server: LM Studio.
- Текущий endpoint: `http://192.168.1.178:1234/v1`.
- Основные кандидаты: `gpt-oss-20b`, `Qwen3.6-35B-A3B`.

## Наблюдения

- Для Qwen reasoning корректнее сравнивать `ON/OFF`, если модель не поддерживает уровни `low/medium/high`.
- Для `gpt-oss-20b` уровень reasoning заметно влияет на длительность агентного цикла.
- Скорость агента определяется не только `tok/s`: важны TTFT, prefill, reasoning tokens, число tool calls и общее время до результата.
- Качество специализированных MCP tools может сильнее влиять на скорость работы, чем разница в скорости генерации модели.

## Принципы настройки

- максимальный разумный GPU offload;
- Flash Attention — использовать, если стабильно работает;
- concurrent predictions = 1 для Hermes на первом этапе;
- не раздувать контекст без необходимости;
- после длинных задач фиксировать состояние в `STATUS.md` и начинать новую сессию;
- сравнивать модели по устойчивости tool use и итоговому времени выполнения задачи.

Подробная история текущих решений пока сохранена в [`../guests/320-ai-control/README.md`](../guests/320-ai-control/README.md).
