# Сеть Proxmox

Здесь фиксируются решения, относящиеся именно к сетевой части Proxmox и его гостей.

## Базовые принципы

- один физический uplink сервера;
- VLAN-aware bridge на Proxmox;
- Proxmox не должен становиться неявным маршрутизатором между сегментами;
- пользовательская маршрутизация, VPN, PBR и DNS относятся к `101-network-gateway`;
- межсегментная маршрутизация и firewall выполняются явно через сетевой шлюз.

## Целевая адресация новой квартиры

Для новой квартиры принимается простое правило:

> **второй октет IPv4-адреса совпадает с номером VLAN, а каждый основной VLAN получает собственную сеть `/16`.**

Базовая схема:

| Сегмент | VLAN | Подсеть | Типичный шлюз |
|---|---:|---|---|
| MAIN | native / untagged | `10.0.0.0/16` | `10.0.0.1` |
| SERVERS | 10 | `10.10.0.0/16` | `10.10.0.1` |
| IOT | 20 | `10.20.0.0/16` | `10.20.0.1` |
| CAMERAS | 30 | `10.30.0.0/16` | `10.30.0.1` |

При появлении новых VLAN сохраняется то же правило, например:

```text
VLAN 40 → 10.40.0.0/16
VLAN 50 → 10.50.0.0/16
```

`MAIN` — специальный случай: `10.0.0.0/16` используется как native/untagged сеть. Это **не означает использование VLAN 0**.

Такое распределение позволяет использовать `/16` без пересечения сетей: `10.10.0.0/16`, `10.20.0.0/16` и `10.30.0.0/16` являются разными маршрутными сетями.

Внутри каждого VLAN третий октет можно использовать для логической группировки устройств без создания дополнительного VLAN. Например в IOT:

```text
10.20.1.x → освещение
10.20.2.x → ESP-контроллеры
10.20.3.x → бытовая техника
```

Это только логическое распределение адресов; все такие устройства по-прежнему находятся в одном VLAN 20 и одной сети `10.20.0.0/16`.

## Текущая квартира и миграция

Действующую сеть `192.168.0.0/16` не требуется немедленно перенумеровывать. Она может продолжать работать в текущем виде до плановой миграции.

Если отдельные VLAN понадобятся ещё до полного перехода на новую адресацию, их следует размещать в непересекающихся сетях `10.<VLAN>.0.0/16`, например:

```text
IOT / VLAN 20     → 10.20.0.0/16
CAMERAS / VLAN 30 → 10.30.0.0/16
```

Это не пересекается с существующей `192.168.0.0/16` и позволяет вводить VLAN постепенно.

## Серверный сегмент

Целевой серверный VLAN новой квартиры — VLAN 10, сеть `10.10.0.0/16`.

Для management IP VM/LXC внутри него сохраняется читаемое соответствие VMID → IP; правило описано в [`vmid-plan.md`](vmid-plan.md).

Детальная конфигурация сетевой VM хранится в `guests/101-network-gateway/` и её `rootfs/`.

Общий проект физической сети, сетевого оборудования, камер и квартиры остаётся в репозитории `zsergeyru/appart-rennovation`. Здесь хранятся только серверные и эксплуатационные сведения, непосредственно относящиеся к Proxmox.

Граница между репозиториями описана в [`apartment-infrastructure.md`](apartment-infrastructure.md).
