# Сеть Proxmox

Здесь фиксируются решения, относящиеся именно к сетевой части Proxmox и его гостей.

Базовые принципы:

- один физический uplink сервера;
- VLAN-aware bridge на Proxmox;
- MAIN — native/untagged;
- VLAN 20 — IOT;
- VLAN 30 — CAMERAS;
- Proxmox не должен становиться неявным маршрутизатором между сегментами;
- пользовательская маршрутизация, VPN, PBR и DNS относятся к `100-network-gateway`.

Детальная конфигурация конкретной сетевой VM хранится в `guests/100-network-gateway/`.

Часть исходных сетевых проектных документов пока находится в репозитории квартиры `zsergeyru/appart-rennovation` (раздел файлов `200...`). По мере переноса сюда должны попадать только серверные/эксплуатационные части, без дублирования общего проекта квартиры.
