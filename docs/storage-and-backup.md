# Storage и резервное копирование

## Принципы

- snapshot не считается заменой полноценного backup;
- перед рискованными изменениями создавать snapshot/backup по ситуации;
- отдельно сохранять конфигурации Home Assistant, Docker Compose, persistent data, сетевую конфигурацию и данные Git-сервисов;
- storage для Frigate и backup не смешивать без контроля retention и свободного места;
- секреты и backup не хранить в открытом Git.

## Открытые вопросы

- постоянное backup-хранилище;
- retention;
- расписание;
- необходимость отдельного Proxmox Backup Server;
- фактическое распределение дополнительного SSD между видео и backup.
