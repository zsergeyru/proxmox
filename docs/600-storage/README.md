# Хранение и резервное копирование

Этот раздел содержит документацию по хранению данных и резервному копированию в проекте: общей модели хранения, требованиям к резервным копиям и причинам ключевых решений.

## Файлы раздела

| Файл | Назначение |
|---|---|
| [`600-overview.md`](600-overview.md) | Общая модель хранения данных, виды данных, места хранения и границы ответственности |
| [`610-backup.md`](610-backup.md) | Политика резервного копирования: что резервируется, с какой периодичностью, сроки хранения, RPO/RTO и требования к проверке восстановления |
| [`620-storage-layout.md`](620-storage-layout.md) | Принятая целевая схема размещения данных PVE и NAS, будущий единый формат `storage.yaml` и границы развёртывания |
| [`630-volume-backup.md`](630-volume-backup.md) | Контракт универсального резервирования постоянных томов через 910 |
| [`690-decisions.md`](690-decisions.md) | Причины ключевых решений по хранению данных и резервному копированию |

## Порядок чтения

Для первого знакомства рекомендуется читать документы в порядке:

`600 → 620 → 610`

[`690-decisions.md`](690-decisions.md) нужен, когда важно понять причины принятых решений, рассмотренные альтернативы и условия их пересмотра.
