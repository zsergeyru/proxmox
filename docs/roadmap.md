# Roadmap

## Ближайшие задачи

1. Зафиксировать фактическую текущую конфигурацию Proxmox-хоста: версия, hostname, management IP, bridge, storage, swap и существующие VMID/CTID.
2. Довести каталоги целевых гостей до схемы из `vmid-plan.md` и заполнять их реальными `guest.yaml` по мере развёртывания.
3. Развернуть и проверить `101-network-gateway` с DNS/VPN/PBR, сохранив независимый аварийный доступ к Proxmox.
4. Подготовить целевую `301-ai-control` на основе решений, проверенных на текущем bootstrap-узле `320-ai-control`, затем перенести управление и только после проверки выводить 320 из эксплуатации.
5. Разделить DevOps и обычные приложения между `311-dev-services` и `321-app-services`.
6. Определить startup/shutdown order и аварийный путь доступа.
7. Довести управление гостями через Proxmox MCP + SSH до повторяемого сценария с проверкой результата.
8. Выбрать VM/LXC для `501-frigate` после теста iGPU/OpenVINO.
9. Определить backup storage, retention и расписание.
10. Переносить из `appart-rennovation` только эксплуатационные серверные сведения, не дублируя общий проект квартиры.

Статусы конкретных гостей ведутся в их собственных `README.md`/`STATUS.md`. Актуальная нумерация VMID/CTID определяется только [`vmid-plan.md`](vmid-plan.md).
