# Архитектура

Этот раздел содержит документацию верхнего уровня по архитектуре проекта Proxmox: состав системы, границы ответственности, модель хранения состояния и причины ключевых архитектурных решений.

## Файлы раздела

| Файл | Назначение |
|---|---|
| [`100-overview.md`](100-overview.md) | Состав системы и связи между её основными частями |
| [`110-system-boundaries.md`](110-system-boundaries.md) | Кто за что отвечает и где проходят границы ответственности |
| [`120-state-model.md`](120-state-model.md) | Где хранятся данные и что считается источником требуемого и фактического состояния |
| [`190-decisions.md`](190-decisions.md) | Почему были приняты ключевые архитектурные решения, какие варианты рассматривались и когда решения стоит пересмотреть |

## Порядок чтения

Для первого знакомства рекомендуется читать документы в порядке:

`100 → 110 → 120`

[`190-decisions.md`](190-decisions.md) нужен, когда важно понять не только текущее устройство системы, но и причины принятых решений.
