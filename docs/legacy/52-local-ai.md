# Локальный AI и локальный запуск моделей

**Тип:** Справочник  
**Статус:** Черновик  
**Основной источник:** Нет — это экспериментальная справка по текущей среде локального запуска моделей; рабочие требования находятся в профильных документах AI Control.

Документ отделяет эксперименты с локальными моделями от эксплуатационной документации VM `ai-control`.

## Текущая платформа локального запуска моделей

- компьютер с GPU: RTX 5060 Ti 16 GB;
- основной сервер с API, совместимым с OpenAI: LM Studio;
- текущий временный адрес сервера: `http://192.168.1.178:1234/v1`;
- этот IP-адрес отражает только текущую установку и не является частью архитектуры проекта. При постоянном использовании локальных моделей предпочтительно обращаться к сервису по стабильному DNS-имени;
- основные кандидаты: `gpt-oss-20b`, `Qwen3.6-35B-A3B`.

## Наблюдения

- Для Qwen режим рассуждений корректнее сравнивать как `ON/OFF`, если модель не поддерживает уровни `low/medium/high`.
- Для `gpt-oss-20b` уровень рассуждений заметно влияет на длительность агентного цикла.
- Скорость агента определяется не только `tok/s`: важны время до первого токена, предварительная обработка контекста, количество токенов рассуждения, число вызовов инструментов и общее время до результата.
- Качество специализированных MCP-инструментов может сильнее влиять на скорость работы, чем разница в скорости генерации модели.

## Принципы настройки

- максимально разумно переносить вычисления на GPU;
- Flash Attention использовать, если он работает стабильно;
- `concurrent predictions = 1` для Hermes на первом этапе;
- не увеличивать контекст без необходимости;
- после длинных задач фиксировать состояние в `STATUS.md` и начинать новую сессию;
- сравнивать модели по устойчивости работы с инструментами и итоговому времени выполнения задачи.
