## 1. Граница документа

Этот документ описывает логическую сеть. Конкретные IP отдельного гостя остаются в его `guest.yaml`, а физическая кабельная инфраструктура относится к отдельному проекту квартиры.

## 2. Основная схема

~~~text
провайдеры / VPN
      ↓
   Keenetic
      ↓
 локальная сеть
      ↓
     PVE
      ↓
    vmbr0
      ↓
 VM / LXC
~~~

Keenetic остаётся физической точкой связи локальной сети с внешними подключениями. PVE предоставляет виртуальные сетевые интерфейсы и мосты, но не принимает на себя роль общего DNS/VPN-маршрутизатора.

## 3. Административная сеть

Управляющий трафик PVE, 910 и обычных гостей должен иметь однозначный адрес и маршрут.

Общая модель гостевого контура допускает:

- вычисляемый статический IPv4;
- явно заданный статический IPv4;
- DHCP.

Точное правило вычисления адресов является ответственностью раздела `300-guests`.

## 4. Гостевые системы

Обычная VM/LXC подключается к принятому PVE bridge и получает сетевые параметры из гостевого контракта.

При изменении адреса или способа получения адреса должны сохраняться:

- достижимость административного интерфейса;
- возможность доверенно определить фактический адрес;
- корректная работа SSH host identity и автоматизации.

## 5. Сетевая VM

Специализированная сетевая VM отделяет от PVE функции:

- DNS;
- `nftables`;
- policy routing;
- VPN;
- дополнительные прокси-механизмы.

Её параметры как VM определяются гостевым контуром. Этот раздел определяет только сетевую роль.

## 6. Сегментация

Новый сетевой сегмент вводится только при понятной границе ответственности или безопасности.

Для каждого сегмента должны быть определены:

- назначение;
- адресный диапазон;
- шлюз;
- связь с остальными сетями;
- допустимые направления трафика.

Сегментация не должна дублировать технические ACL приложений и OpenBao.

## 7. Проверка

Проверка сетевой схемы должна подтверждать:

- отсутствие пересечения адресных диапазонов;
- доступность PVE и управляющего контура;
- корректный шлюз гостей;
- отсутствие непредусмотренной маршрутизации через PVE;
- возможность определить административный адрес DHCP-гостя доверенным способом.
