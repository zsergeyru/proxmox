# Сеть

Этот раздел содержит документацию по сетевой части проекта: общей схеме сети, адресации, DNS, маршрутизации, VPN и причинам ключевых сетевых решений.

## Файлы раздела

| Файл | Назначение |
|---|---|
| [`400-overview.md`](400-overview.md) | Общая модель сети, основные компоненты, их роли и границы ответственности |
| [`410-network-layout.md`](410-network-layout.md) | Логическая схема сети, сетевые сегменты, адресация, шлюзы и связь с сетевыми мостами PVE |
| [`420-dns.md`](420-dns.md) | Устройство DNS, роль SmartDNS, вышестоящие DNS-сервисы и связь DNS с сетевыми правилами |
| [`430-routing.md`](430-routing.md) | Маршрутизация, policy routing, nftables, NAT и правила выбора сетевого пути |
| [`440-vpn.md`](440-vpn.md) | VPN-интерфейсы, их роль в общей схеме и взаимодействие с маршрутизацией |
| [`490-decisions.md`](490-decisions.md) | Причины ключевых решений по DNS, маршрутизации, VPN и распределению сетевых функций |

## Порядок чтения

Для первого знакомства рекомендуется читать документы в порядке:

`400 → 410 → 420 → 430 → 440`

[`490-decisions.md`](490-decisions.md) нужен, когда важно понять причины принятых сетевых решений, рассмотренные альтернативы и условия их пересмотра.
