# Безопасность

Раздел `700` описывает **как компоненты проекта доверяют друг другу и какие полномочия между ними разрешены**.

Здесь не описывается, как установить OpenBao, Semaphore или файлы SSH на конкретном госте. Такие подробности находятся в локальной документации соответствующего гостя.

## Файлы раздела

| Файл | Главный вопрос |

| [`700-overview.md`](700-overview.md) | как в целом устроено доверие между PVE, infra-manager, OpenBao, Semaphore, Git и гостями |
| [`710-pve-access.md`](710-pve-access.md) | кто и через какие каналы может управлять Proxmox VE |

## Как читать

Для общего понимания:

```text
700 → общая модель
 ├─ 710 → PVE
 ├─ 720 → SSH
 ├─ 730 → Git
 ├─ 740 → OpenBao
 ├─ 750 → access.yaml
 ├─ 780 → фактическое состояние
 └─ 790 → причины решений
```

Если нужен ответ на вопрос **как конкретно развернуть сервис**, нужно переходить в локальную документацию гостя. Например, реализация OpenBao и Semaphore на 910 описана в `infrastructure/guests/910-infra-manager/docs/`.
