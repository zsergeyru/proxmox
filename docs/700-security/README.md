# Безопасность

Этот раздел содержит документацию по безопасности проекта: общим правилам защиты, доступу к Proxmox, административному SSH и причинам ключевых решений.

## Файлы раздела

| Файл | Назначение |
|---|---|
| [`700-overview.md`](700-overview.md) | Общая политика безопасности, основные принципы и границы ответственности |
| [`710-pve-access.md`](710-pve-access.md) | Учётные записи Proxmox, API-токены, роли, привилегии, ACL и границы доступа |
| [`720-ssh-access.md`](720-ssh-access.md) | Административный SSH-доступ, инфраструктурные SSH-ключи, их регистрация, распространение и отзыв |
| [`730-openbao.md`](730-openbao.md) | Центральное хранение машинных секретов в OpenBao, политики, AppRole, unseal и восстановление |
| [`790-decisions.md`](790-decisions.md) | Причины ключевых решений по безопасности и управлению доступом |

## Порядок чтения

Для первого знакомства рекомендуется читать документы в порядке:

`700 → 710 → 720 → 730`

[`790-decisions.md`](790-decisions.md) нужен, когда важно понять причины принятых решений, рассмотренные альтернативы и условия их пересмотра.
