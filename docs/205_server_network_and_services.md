# Совместимая ссылка на старую документацию

Этот файл оставлен под старым именем, чтобы ссылки из перенесённого архитектурного документа не ломались.

Документация сейчас разделяется так:

- серверная и эксплуатационная часть Proxmox — в этом репозитории, прежде всего `docs/` и `guests/`;
- общий проект сети, квартиры, камер и связанной инфраструктуры — в `https://github.com/zsergeyru/appart-rennovation`, где исходные документы раздела `200...` пока остаются источником подробностей;
- AI Control — `docs/ai-control.md` и `guests/320-ai-control/`;
- Frigate — `guests/500-frigate/`;
- сеть/DNS/VPN/PBR — `docs/network.md` и `guests/100-network-gateway/`.

По мере переноса старых материалов эту stub-страницу можно заменить профильным документом или удалить после обновления всех ссылок.
