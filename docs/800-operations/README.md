# Эксплуатация

Этот раздел содержит практическую документацию по развёртыванию, регулярному обслуживанию и восстановлению проекта.

## Файлы раздела

| Файл | Назначение |
|---|---|
| [`800-overview.md`](800-overview.md) | Общая модель эксплуатации проекта и связь между развёртыванием, обслуживанием и восстановлением |
| [`810-deployment.md`](810-deployment.md) | Сквозная инструкция по развёртыванию проекта от чистого PVE до готовой рабочей системы |
| [`820-maintenance.md`](820-maintenance.md) | Регулярное обслуживание работающей инфраструктуры, проверки и плановые действия |
| [`830-recovery.md`](830-recovery.md) | Проверка восстановления и действия при сбоях, включая восстановление гостевых систем и PVE-хоста |

## Порядок чтения

Для первого знакомства рекомендуется читать документы в порядке:

`800 → 810 → 820`

[`830-recovery.md`](830-recovery.md) используется при проверке восстановления и при аварийных ситуациях.
