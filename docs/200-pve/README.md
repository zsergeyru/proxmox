| [`210-host-bootstrap.md`](210-host-bootstrap.md) | Контракт первоначального создания и восстановления `910 infra-manager` |
| [`220-host-configuration.md`](220-host-configuration.md) | Обязательное постоянное состояние PVE-хоста |

| [`290-decisions.md`](290-decisions.md) | Причины ключевых решений по PVE-хосту |

Для первого знакомства достаточно прочитать `200-overview.md`.
