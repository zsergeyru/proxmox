Документация конкретного `910 infra-manager` находится в [`../../infrastructure/guests/910-infra-manager/README.md`](../../infrastructure/guests/910-infra-manager/README.md).

## Основная граница

На PVE не должен существовать постоянный проектный контур развёртывания с Git-копией, `pvedeploy`, `deploy-guest` и собственным состоянием.

```text
PVE
└─ bootstrap-pve.sh
   └─ 910 infra-manager
      └─ дальнейшее управление инфраструктурой
```
