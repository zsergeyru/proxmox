# План VMID / CTID

Функциональная нумерация используется для новых VM/LXC. Номер не определяет порядок запуска.

| Диапазон | Назначение |
|---|---|
| `100–199` | сеть и базовая инфраструктура |
| `200–299` | Home Assistant и автоматика |
| `300–399` | прикладные, DevOps- и AI-сервисы |
| `400–499` | мониторинг и обслуживание |
| `500–599` | видео и камеры |
| `600–699` | временные и экспериментальные VM/LXC |
| `900–999` | legacy-системы |

## Текущий целевой план

- `100` — `network-gateway` (VM)
- `200` — `ha-main` (LXC)
- `201` — `ha-test` (LXC)
- `202` — `ha-flat2` (LXC, при необходимости)
- `210` — `automation-services` (LXC)
- `300` — `app-services` (LXC)
- `310` — резерв под отдельный Homarr при необходимости
- `320` — `ai-control` (VM)
- `330` — `ai-services` (LXC)
- `400` — `monitoring` (LXC)
- `410` — резерв под `backup-services`
- `500` — `frigate` (VM/LXC после теста)

Существующие legacy VM не перенумеровывать только ради унификации.
