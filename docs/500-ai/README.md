# AI

Этот раздел содержит документацию по AI-контуру квартиры: его роли, внутреннему устройству, способам управления домашними системами и причинам ключевых решений.

## Файлы раздела

| Файл | Назначение |
|---|---|
| [`500-overview.md`](500-overview.md) | Общая роль AI-контура квартиры, его место в архитектуре и области работы |
| [`510-ai-control.md`](510-ai-control.md) | Устройство AI Control, агенты, модели, инструменты, память и события |
| [`520-ai-management.md`](520-ai-management.md) | Как AI выбирает механизм управления, оценивает уровень действия и проверяет результат |
| [`590-decisions.md`](590-decisions.md) | Причины ключевых решений по устройству и использованию AI-контура |

## Порядок чтения

Для первого знакомства рекомендуется читать документы в порядке:

`500 → 510 → 520`

[`590-decisions.md`](590-decisions.md) нужен, когда важно понять причины принятых решений, рассмотренные альтернативы и условия их пересмотра.
