# Interfaces

Каталог содержит пользовательские интерфейсы к AI-агентам управляющего контура.

Сюда относятся, например:

- web UI для Hermes или общего agent gateway;
- голосовой интерфейс;
- API/UI-прокси, если он относится именно к `320-ai-control`;
- другие интерфейсные компоненты, через которые пользователь взаимодействует с агентами.

Общие STT/TTS-сервисы сюда не помещаются: они относятся к `330-ai-services`, потому что могут использоваться не только агентами, но и Home Assistant, панелями и другими приложениями.
