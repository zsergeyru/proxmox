# Services

Каталог содержит вспомогательные сервисы, которые работают именно внутри `320-ai-control` и не являются самостоятельными AI-агентами, MCP или пользовательскими интерфейсами.

Примеры:

- внутренние backend-сервисы управляющего контура;
- общие компоненты, которыми пользуются несколько агентов внутри этой VM;
- небольшие инфраструктурные сервисы, привязанные именно к `320-ai-control`.

Docker lifecycle не требует отдельного deploy-MCP. Агент управляет сервисами через SSH и обычные Docker / Docker Compose команды.

Если сервис реально работает на другой VM/LXC, его код и конфигурация должны храниться в каталоге соответствующего гостя, например:

```text
guests/330-ai-services/services/<name>/
```

а не в `320-ai-control/services/`.
