# Hermes

Hermes — основной AI-агент управляющего контура `320-ai-control`.

Он рассматривается как администратор домашней инфраструктуры, а не только как агент собственного Docker-контейнера.

Основные механизмы управления:

- Proxmox MCP — создание и жизненный цикл VM/LXC;
- SSH — настройка ОС, файлов, systemd, Docker/Compose и приложений внутри `320-ai-control` и других VM/LXC;
- специализированные MCP — когда они дают удобный прикладной API к конкретной системе.

Файлы Hermes, включая будущий `AGENTS.md`, конфигурацию и служебные скрипты, должны храниться в этом каталоге после синхронизации с рабочей VM.

Секреты, приватные SSH-ключи, токены и пароли в Git не добавлять.
