# MCP

Каталог содержит конфигурации и исходники MCP-сервисов, используемых агентами `320-ai-control`.

MCP здесь не делятся на «разрешённые агенту» и «запрещённые агенту» категории. Если агенту требуется новый MCP для управления Proxmox, Home Assistant, сетью, Git или другой системой, он должен уметь установить, настроить, обновить и сопровождать этот компонент.

Базовое разделение ответственности:

```text
Proxmox MCP
→ управление уровнем виртуализации: VM/LXC, ресурсы, lifecycle, snapshots, backups

SSH
→ универсальное управление внутри гостевых ОС: пакеты, файлы, systemd, Docker/Compose и приложения

другие MCP
→ специализированные API там, где они реально удобнее обычного SSH/API
```

`deploy-mcp` больше не является частью целевой архитектуры. Для управления Docker и сервисами используется SSH.

Секреты, токены, пароли и приватные ключи в Git не добавлять.
