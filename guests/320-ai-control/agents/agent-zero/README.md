# Agent Zero

Agent Zero планируется как второй агент в `320-ai-control` для сравнения с Hermes и возможного использования в отдельных сценариях.

Цель структуры — не привязывать инфраструктуру к одному агенту. Общие MCP, SSH-доступ к гостям и общие сервисы должны быть доступны нескольким агентам без дублирования файлов.

На первом этапе Agent Zero можно разворачивать отдельно и сравнивать с Hermes на одинаковой модели и одинаковых задачах. Конкретные настройки будут добавляться сюда по мере установки.
