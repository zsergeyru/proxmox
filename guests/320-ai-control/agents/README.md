# Agents

Каталог содержит AI-агентов, работающих в `320-ai-control`.

Каждый агент хранится в отдельном подкаталоге:

```text
agents/
├── hermes/
├── agent-zero/
└── ...
```

Внутри каталога конкретного агента хранятся относящиеся к нему файлы: конфигурация, инструкции (`AGENTS.md`), Dockerfile/Compose-фрагменты при необходимости, скрипты, документация и `STATUS.md` для длинных работ.

Общие MCP и общие сервисы не следует дублировать внутри каталога агента. Они находятся соответственно в `../mcp/` и `../services/`.

Агенты могут иметь широкие административные права и управлять всей домашней инфраструктурой через Proxmox MCP и SSH. Защита строится прежде всего на Git, snapshots, backups и возможности отката, а не на множестве локальных песочниц.
