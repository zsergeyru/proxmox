# Guests

Каждый каталог соответствует одной целевой VM/LXC и собирает в одном месте её документацию и конфигурацию.

Правило именования:

```text
<VMID>-<name>/
```

Внутри конкретного гостя допускаются:

- `README.md` — назначение, ресурсы, зависимости, статус;
- `compose.yaml` — только когда существует реальная Docker-конфигурация;
- конфиги сервисов;
- `STATUS.md` — текущее состояние длинных работ;
- скрипты, относящиеся только к этому гостю.

Общие playbook/roles не дублировать по гостям — они хранятся в `/ansible`.
