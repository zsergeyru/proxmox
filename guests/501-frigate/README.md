# 501 — Frigate

**Тип:** ещё не выбран; VM или LXC после практического теста  
**Назначение:** видеонаблюдение, запись и детекция событий.

Целевые функции:

- RTSP/ONVIF;
- запись основного потока камер;
- детекция по дополнительному потоку;
- OpenVINO;
- использование Intel N150/iGPU;
- события для Home Assistant.

Coral TPU на первом этапе не требуется. Окончательный выбор VM/LXC и объём хранилища фиксируются после теста iGPU/OpenVINO и измерения фактического битрейта камер.

`guest.yaml` уже существует, чтобы резерв VMID и известные сетевые параметры были машинно-читаемыми. До принятия типа и ресурсов он намеренно содержит:

```yaml
type: undecided
deployable: false
```

Поэтому универсальный `deploy-guest` обязан отказаться создавать `501`.

После практического теста:

```text
выбрать VM или LXC
→ зафиксировать ресурсы, источник и передачу устройств
→ проверить манифест
→ только затем установить deployable: true
```

Имена полей YAML оставлены без перевода как часть машинной схемы.

Конфигурация после появления реального развёртывания хранится под `rootfs/`.
