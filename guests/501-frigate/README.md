# 501 — Frigate

**Тип:** ещё не выбран; VM или LXC после практического теста  
**Назначение:** видеонаблюдение, запись и детекция событий.

Целевые функции:

- RTSP/ONVIF;
- запись main stream;
- детекция по substream;
- OpenVINO;
- использование Intel N150/iGPU;
- события для Home Assistant.

Coral TPU на первом этапе не требуется. Окончательный выбор VM/LXC и объём storage фиксируются после теста iGPU/OpenVINO и фактического bitrate камер.

`guest.yaml` теперь существует, чтобы резерв VMID и известные сетевые параметры тоже были машинно-читаемыми. До принятия типа и ресурсов он намеренно содержит:

```yaml
type: undecided
deployable: false
```

Поэтому универсальный deployer обязан отказаться создавать `501`.

После практического теста:

```text
выбрать vm или lxc
→ зафиксировать resources/source/device passthrough
→ проверить manifest
→ только затем deployable: true
```

Конфигурация после появления реального развёртывания хранится под `rootfs/`.
