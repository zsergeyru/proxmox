# 501 — Frigate

**Тип:** VM или LXC после практического теста  
**Назначение:** видеонаблюдение, запись и детекция событий.

Целевые функции:

- RTSP/ONVIF;
- запись main stream;
- детекция по substream;
- OpenVINO;
- использование Intel N150/iGPU;
- события для Home Assistant.

Coral TPU на первом этапе не требуется. Окончательный выбор VM/LXC и объём storage фиксируются после теста iGPU/OpenVINO и фактического bitrate камер.

Конфигурация после появления реального развёртывания хранится под `rootfs/`.
