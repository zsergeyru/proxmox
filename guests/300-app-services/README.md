# 300 — app-services

**Тип:** LXC  
**Назначение:** небольшие прикладные и DevOps-сервисы общего назначения.

Планируемые Docker-сервисы:

- Homarr;
- Gitea/Gogs;
- Jenkins;
- password server;
- torserver;
- другие некритичные приложения того же класса.

Homarr используется как навигационный интерфейс по инфраструктуре, но не заменяет специализированные UI Proxmox, Home Assistant и других систем.
