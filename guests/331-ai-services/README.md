# 331 — ai-services

**Тип:** LXC  
**Назначение:** общие AI-сервисы, не зависящие от конкретного агента.

Планируемый Docker Compose:

- Whisper / faster-whisper — общий API распознавания речи (STT);
- TTS — Kokoro, Piper или другой выбранный движок синтеза речи.

Этими API могут пользоваться Hermes, Home Assistant, голосовые панели, Open WebUI и будущие приложения. Перезапуск `301-ai-control` или текущего временного `320-ai-control` не должен останавливать общие голосовые функции.

Compose-файлы и конфигурация после появления реальной установки хранятся под `rootfs/`.
