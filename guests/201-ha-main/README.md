# 201 — ha-main

**Тип:** LXC  
**Статус:** резерв под возможную будущую миграцию Home Assistant.

Текущая рабочая система Home Assistant — VM `100-haos`. Гостевая система `201-ha-main` не должна создаваться только ради новой нумерации или замены работающего HAOS.

`201` используется только если появится практическая причина перейти на другую модель размещения Home Assistant и будет отдельно принят план миграции.

Если `201` будет развёрнут, он не должен содержать общесерверные сервисы вроде DNS, Git, мониторинга или Whisper/TTS. Инфраструктура MQTT/Zigbee2MQTT/ESPHome остаётся в `211-automation-services`.

Ресурсы и способ установки Home Assistant определяются только перед фактическим развёртыванием. Файлы гостевой ОС должны храниться под `rootfs/`.
