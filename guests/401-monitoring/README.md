# 401 — monitoring

**Тип:** LXC  
**Назначение:** наблюдение за инфраструктурой независимо от систем, которые он контролирует.

Минимальный состав:

- Uptime Kuma.

Возможное развитие:

- Grafana;
- Prometheus;
- InfluxDB;
- центральный syslog;
- NetFlow collector;
- локальный NTP.

Compose и конфиги после появления реальной конфигурации хранятся под `rootfs/`.
