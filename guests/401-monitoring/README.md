# 401 — monitoring

**Тип:** LXC  
**Назначение:** наблюдение за инфраструктурой независимо от систем, которые он контролирует.

Минимальный состав:

- Uptime Kuma.

Возможное развитие:

- Grafana;
- Prometheus;
- InfluxDB;
- центральный syslog;
- сборщик NetFlow;
- локальный NTP.

Compose-файлы и конфигурация после появления реальной установки хранятся под `rootfs/`.
