# 321 — app-services

**Тип:** LXC  
**Назначение:** небольшие прикладные сервисы общего назначения.

Планируемые сервисы:

- Homarr;
- password server;
- torserver;
- другие некритичные приложения того же класса.

Git/CI вынесены в `311-dev-services`.

Homarr используется как навигационный интерфейс по инфраструктуре, но не заменяет специализированные UI Proxmox, Home Assistant и других систем. Compose и конфиги после появления реальной конфигурации хранятся под `rootfs/`.
