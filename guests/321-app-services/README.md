# 321 — app-services

**Тип:** LXC  
**Назначение:** небольшие прикладные сервисы общего назначения.

Планируемые сервисы:

- Homarr;
- сервер паролей;
- torserver;
- другие некритичные приложения того же класса.

Git/CI вынесены в `311-dev-services`.

Homarr используется как навигационный интерфейс по инфраструктуре, но не заменяет специализированные веб-интерфейсы Proxmox, Home Assistant и других систем. Compose-файлы и конфигурация после появления реальной установки хранятся под `rootfs/`.
