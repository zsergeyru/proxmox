# 301 — ai-control

**Тип:** VM  
**Статус:** целевой управляющий узел; ещё не заменяет текущий `320-ai-control` до завершения проверки.

`301-ai-control` является целевой VM центрального AI-контура управления домашней инфраструктурой.

Базовые механизмы:

```text
Proxmox MCP → VM/LXC, ресурсы, lifecycle, snapshots, backups
SSH         → ОС, файлы, systemd, Docker/Compose и приложения
```

Отдельный универсальный `deploy-mcp` не используется.

До миграции текущие рабочие решения и ADR находятся в `../320-ai-control/`. При развёртывании `301` воспроизводимая конфигурация переносится через Git и `rootfs/`, после чего отдельно проверяются Hermes, Proxmox MCP, SSH и управление другими гостями.

`320-ai-control` выводится из эксплуатации только после успешной проверки `301`.
