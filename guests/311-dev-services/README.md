# 311 — dev-services

**Тип:** LXC  
**Назначение:** сервисы разработки и CI/CD, отделённые от обычных прикладных сервисов.

Планируемые сервисы:

- Gitea или Gogs;
- Jenkins;
- другие инструменты разработки, сборки и CI при необходимости.

Homarr и обычные пользовательские приложения сюда не относятся; они размещаются в `321-app-services`. Compose, конфиги и локальный код после появления реальной конфигурации хранятся под `rootfs/`.
