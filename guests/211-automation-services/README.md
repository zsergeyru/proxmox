# 211 — automation-services

**Тип:** LXC  
**Назначение:** инфраструктурные сервисы домашней автоматики.

Планируемый Docker Compose:

- Mosquitto / MQTT;
- Zigbee2MQTT;
- ESPHome Dashboard.

Отказ этого гостя не должен затрагивать DNS, Git, monitoring и другие несвязанные сервисы. Compose и конфиги после появления реальной конфигурации размещаются под `rootfs/` по фактическому пути установки.
