# 211 — automation-services

**Тип:** LXC  
**Назначение:** инфраструктурные сервисы домашней автоматики.

Планируемый Docker Compose:

- Mosquitto / MQTT;
- Zigbee2MQTT;
- ESPHome Dashboard.

Отказ этой гостевой системы не должен затрагивать DNS, Git, мониторинг и другие несвязанные сервисы. Compose-файлы и конфигурация после появления реальной установки должны разворачиваться явными Ansible-ролями по фактическим путям назначения.
