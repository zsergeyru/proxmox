# 401 — monitoring

**Тип:** LXC  
**Назначение:** наблюдение за инфраструктурой независимо от систем, которые он контролирует.

**Статус нумерации:** `401` — историческое описание, **целевой VMID мониторинга — `930`** согласно [общему плану нумерации](../../../docs/300-guests/340-vmid-plan.md). Новый гость мониторинга должен получать `930`. Существующий каталог и `guest.yaml` не перенумеровываются автоматически: перед миграцией нужно проверить наличие рабочего 401 в PVE, постоянные данные, сетевые и OpenTofu-ссылки. Смена номера — отдельная подтверждаемая операция без удаления состояния.

Минимальный состав:

- Uptime Kuma.

Возможное развитие:

- Grafana;
- Prometheus;
- InfluxDB;
- центральный syslog;
- сборщик NetFlow;
- локальный NTP.

Compose-файлы и конфигурация после появления реальной установки должны разворачиваться явными Ansible-ролями.
