# 220 — automation-services

**Тип:** LXC  
**Назначение:** инфраструктурные сервисы домашней автоматики.

Планируемый Docker Compose:

- Mosquitto / MQTT;
- Zigbee2MQTT;
- ESPHome Dashboard.

Отказ этой гостевой системы не должен затрагивать DNS, Git, мониторинг и другие несвязанные сервисы. Файлы Compose и конфигурации после появления реальной установки размещаются под `rootfs/` по фактическому пути назначения.
