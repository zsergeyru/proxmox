# Предварительный просмотр infra-web

Контейнер `infra-web` включается только через профиль Docker Compose `preview`.
Он слушает **только 127.0.0.1:3104 внутри управляющего LXC** и читает
`/mnt/persistent-state/operations` в режиме только чтения.

В этой итерации доступен список заданий с периодическим обновлением, а не
готовая административная панель. Вход, HTTPS, права действий и защищённая
связь с системным исполнителем будут подключены до включения сервиса в
обычном составе. Открывать порт в сеть и публиковать его через шлюз запрещено.
