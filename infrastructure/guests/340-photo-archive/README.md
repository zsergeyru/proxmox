# 340 — фотоархив

**Статус:** Immich v3.3.1 развёрнут и работает на PVE; первая настройка пользователей и библиотеки подготовлена в проекте для следующего `deploy`.

Гость 340 предоставляет постоянный доступ к семейному фотоархиву через Immich. Веб-интерфейс Immich доступен на `http://192.168.3.40:2283/`, локальная страница Homepage со ссылкой на Immich — на `http://192.168.3.40:3001/`. Полный `infra-manager status 340` показывает обе ссылки и проверяет доступность приложения. Оригиналы находятся на хранилище Proxmox; тематическая и физическая сортировка не выполняется. Просмотр, альбомы, люди и поиск доступны независимо от работы основного компьютера.

Первоначальный режим: LXC с Immich `v3.3.1`, API, фоновыми заданиями, PostgreSQL и Redis. После подготовки отдельного обработчика Windows фоновые задания могут перейти на основной компьютер вместе с машинным обучением и LM Studio/Qwen. Это одна логическая установка Immich с общей базой, очередью и файлами, а не две самостоятельные галереи.

Созданы `guest.yaml`, `provision.yaml` и роль Ansible `photo_archive` с подключением через общий сценарий. Перед Ansible штатный `infra-manager deploy 340` подготавливает на основном NVMe Proxmox в `local-lvm` два тонких логических тома: 240 ГиБ для фотографий и медиаданных, 40 ГиБ для общего постоянного состояния LXC. Гость получает `mp0` для оригиналов (только чтение), `mp1` для своей папки базы и настроек на общем томе 40 ГиБ и `mp2` для медиаданных Immich (запись). При повторном развёртывании существующие тома и данные не переформатируются. Роль откажет при отсутствии любого подключения. `status.yaml` проверяет Docker и HTTP Immich; общая роль портала создаёт Homepage с ссылкой на галерею. Immich с PostgreSQL и Redis успешно запущен; после слияния изменений первый `deploy 340` должен автоматически подготовить три учётные записи, общую библиотеку и начальные настройки. Перенос исторических фотоархивов с Windows (~181,5 ГБ) и подключение обработчика Windows остаются отдельными шагами. См. [развёртывание](docs/deployment.md).


Дополнительные службы для воспоминаний, управления альбомами и описания
фотографий настраиваются штатным развёртыванием. См.
[дополнения](docs/addons.md).
