# 340 — фотоархив

**Статус:** настройка в процессе; автоматическая подготовка постоянных томов реализована, успешное развёртывание Immich на PVE ещё не подтверждено.

Гость 340 предоставляет постоянный доступ к семейному фотоархиву через Immich. Оригиналы находятся на хранилище Proxmox; тематическая и физическая сортировка не выполняется. Просмотр, альбомы, люди и поиск доступны независимо от работы основного компьютера.

Принятое решение: лёгкий LXC с Immich API, PostgreSQL и Redis; фоновые работники Immich, служба машинного обучения и LM Studio с Qwen работают на основном компьютере Windows. Это одна логическая установка Immich с общей базой, очередью и файлами, а не две самостоятельные галереи.

Созданы `guest.yaml`, `provision.yaml` и роль Ansible `photo_archive` с подключением через общий сценарий. Перед Ansible штатный `infra-manager deploy 340` подготавливает на основном NVMe Proxmox в `local-lvm` два тонких логических тома: 240 ГиБ для фотографий и медиаданных, 40 ГиБ для общего постоянного состояния LXC. Гость получает `mp0` для оригиналов (только чтение), `mp1` для своей папки базы и настроек на общем томе 40 ГиБ и `mp2` для медиаданных Immich (запись). При повторном развёртывании существующие тома и данные не переформатируются. Роль откажет при отсутствии любого подключения. `status.yaml` с дополнительными проверками пока не создавался. Успешный запуск Immich и подключение Windows ещё необходимо проверить. См. [развёртывание](docs/deployment.md).
