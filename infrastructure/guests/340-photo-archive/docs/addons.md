# Дополнения фотоархива 340

## Назначение и состав

Дополнения работают рядом с основным Immich в одном Docker Compose. Их
собственные параметры и результаты сохраняются на постоянном томе 340.
Повторный `infra-manager deploy 340` не меняет настройки и секреты, созданные
ранее. Оригиналы и таблицы Immich не очищаются.

| Служба | Адрес в домашней сети | Начальное состояние |
| --- | --- | --- |
| Immich Memories Notify | `http://<адрес-340>:5000` | Панель запущена, уведомления не настроены |
| Immich Power Tools | `http://<адрес-340>:8001` | Образ загружен, запуск выключен |
| Immich Analyze | Нет веб-интерфейса | Образ загружен, запуск выключен |

Файлы настроек лежат в `/mnt/persistent-state/secrets/`, данные — в
`/mnt/persistent-state/addons/`. Все три образа загружаются при развёртывании,
но выключенные службы не занимают память и не получают доступ к фотографиям.
Состав и переключатели заданы в `provision.yaml → photo_archive.addons`.

## Ежедневные воспоминания

При первом развёртывании создаются:

- `secrets/immich-memories.env` — адрес Immich и случайный пароль панели;
- `addons/memories/config.yaml` — начальные настройки без секретов;
- `addons/memories/state/` — состояние уведомлений и повторов.

Откройте домашний адрес 340 на порту 5000 и пройдите начальную настройку.
Имя администратора панели — `admin`, пароль — значение `DASHBOARD_TOKEN`
в `secrets/immich-memories.env`. Просматривать файл только из доверенной
оболочки PVE: `pct exec 340 -- cat /mnt/persistent-state/secrets/immich-memories.env`.
Не включайте публичный доступ к панели до настройки аутентификации.

В Immich для каждого человека, которому нужны воспоминания, создайте ключ
API в настройках его учётной записи. Добавьте его через панель дополнения,
выберите подходящие события и расписание. **Панель сама по себе ещё не
отправляет уведомления Android.** Для этого потребуется отдельно развернуть
ntfy с доступом по HTTPS из интернета, создать пользователей и темы,
установить приложение ntfy на телефоны. Затем укажите адрес ntfy и параметры
доступа в панели воспоминаний. Не выбирайте в мастере установку встроенного
ntfy: у контейнера намеренно нет доступа к управляющему сокету Docker.

Создание коллажей может добавлять файлы и альбомы в Immich: перед включением
проверьте права API и действие настройки «сохранять коллажи».

## Инструменты управления фотоархивом

Power Tools подключается и к API Immich, и к его PostgreSQL. Доступ к базе
возможен только внутри сети Docker; внешний порт PostgreSQL **не** открывается.

1. Сделайте резервную копию PostgreSQL и убедитесь, что она восстанавливается.
2. В Immich создайте отдельный ключ API от подходящей учётной записи с
   необходимыми разрешениями. Для ряда действий Power Tools запрашивает широкие
   разрешения. Не публикуйте ключ.
3. Запишите его в `/mnt/persistent-state/secrets/immich-power-tools.env`
   после `IMMICH_API_KEY=`. Остальные параметры и случайный `JWT_SECRET`
   уже созданы и **не заменяются** при повторном развёртывании.
4. Измените `photo_archive.addons.power_tools.enabled` на `true` в
   `provision.yaml`, выполните `infra-manager deploy 340`.
5. Откройте домашний адрес гостя 340 на порту 8001 и проверьте вход, чтение
   людей и альбомов. Массовые изменения сначала испытайте на нескольких
   записях. Не объединяйте лица автоматически без проверки.

Не подключайте Power Tools через публичный обратный прокси без отдельной
авторизации.

## Описания фотографий через LM Studio

Immich Analyze получает изображения по API Immich и записывает описания через
него же. Встроенный режим — **только наблюдение за новыми снимками**, а не
массовое изменение старого архива. Существующие описания не перезаписываются.

1. На Windows в LM Studio включите сервер API, доступный с IP гостя 340.
   Используйте модель, которая принимает изображения. Сервер обычно работает
   на порту 1234; точный адрес и имя модели узнайте в LM Studio.
2. Создайте ключ API Immich с доступом к нужным фотографиям.
3. В `/mnt/persistent-state/secrets/immich-analyze.env` задайте
   `IMMICH_API_KEY`, `IMMICH_ANALYZE_HOSTS=http://<Windows-IP>:1234` и
   `IMMICH_ANALYZE_MODEL_NAME` — точный идентификатор загруженной модели.
   Тип интерфейса задан как `llamacpp` для совместимого с OpenAI API.
   **Совместимость LM Studio с этим режимом требуется подтвердить тестом**.
4. Проверьте сетевой доступ к LM Studio только из нужной домашней сети,
   включите проверку токена при наличии и не открывайте порт в интернет.
5. После успешной пробы на небольшом количестве снимков поменяйте
   `photo_archive.addons.analyze.enabled` на `true` и выполните
   `infra-manager deploy 340`.

В начальном файле стоят `IMMICH_ANALYZE_MODE=monitor`,
`IMMICH_ANALYZE_OVERWRITE_POLICY=none` и
`IMMICH_ANALYZE_MAX_CONCURRENT=1`. Для последующей обработки старых снимков
отдельно выберите пакетный режим и проверьте результат на пробной подборке.
При выключенной Windows служба может ожидать её включения, но точное
возобновление заданий нужно испытать, прежде чем запускать большой архив.

## Проверка и восстановление

Команды внутри гостя 340:

```bash
docker compose -f /opt/photo-archive/compose/docker-compose.yml ps
docker logs --tail=50 immich_memories
docker logs --tail=50 immich_power_tools
docker logs --tail=50 immich_analyze
```

Для выключенных дополнений отсутствие контейнера нормально. Не используйте
`docker compose --profile disabled-addons up`: это принудительно запускает
неподготовленные службы.

При восстановлении сохраняйте `/mnt/persistent-state/secrets/immich-*.env`
и `/mnt/persistent-state/addons/` вместе с PostgreSQL и медиаданными.
Подготовка параметров создаёт только отсутствующие файлы. Если файл секрета
пропал, а приложение уже настроено, ключи нужно восстановить из резервной
копии либо создать повторно через Immich. Пользовательские пароли Immich не
сбрасываются.

Обновления сторонних образов могут нарушить совместимость с закреплённой
версией Immich `v3.3.1`. Перед обновлением проверить выпуски дополнений,
сделать резервную копию и протестировать интерфейс и доступ к базе.
