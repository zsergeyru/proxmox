# Решения по гостю 340

## Принятые решения

1. **Immich сохраняем.** Богатый поиск, лица, альбомы, мобильный доступ важнее минимального потребления ресурсов.
2. **Одна установка, два сервера приложения.** На постоянно включённом LXC 340 — API, PostgreSQL, Redis и веб-интерфейс. Пока Windows не настроен, фоновые задания также выполняются в 340; после настройки обработчиков они переходят на Windows вместе с Immich ML и LM Studio/Qwen. Общая база и общие медиаданные; два независимо управляемых фотокаталога не создаются.
3. **LXC вместо VM на первом этапе.** Приоритет — меньшие расходы памяти и прямое подключение каталога PVE. Компромисс: Docker в LXC не является рекомендуемой конфигурацией Immich. Перед вводом обязательно испытание.
4. **PostgreSQL остаётся.** Это обязательный компонент выбранной галереи; замена на SQLite не предусматривается.
5. **Физической сортировки нет.** Оригиналы остаются в одном каталоге, категории и альбомы — в базе. Дубликаты и сомнительное качество показывать для проверки. Только пользователь удаляет фотографии через корзину Immich; срок хранения перед окончательным удалением — 30 дней, если он не очистит корзину раньше. Внешняя библиотека доступна Immich на запись.
6. **Пересоздаваемый LXC.** На существующем NVMe Proxmox в `local-lvm` два тома: 240 ГиБ для оригиналов и медиаданных (`mp0`, `mp2`) и общий том 40 ГиБ для постоянных состояний LXC, включая базу и настройки 340 (`mp1`). Они вне rootfs, и резервировать их нужно отдельно.
7. **Три места хранения.** Яндекс Диск → Windows → Proxmox, односторонняя передача без удаления. Резервирование базы отдельно.
8. **Дальнейший перенос на NAS.** Сейчас два логических тома на NVMe PVE 512 ГБ; после появления NAS фотографии и крупные медиаданные можно перенести туда. Том состояний останется локальным и может увеличиваться.
9. **Первоначальные ресурсы — только гипотеза.** 2 vCPU и 4 ГБ ОЗУ для пробного LXC; итоговый размер определяется испытаниями.
10. **Без специального развёртывания 340.** Использовать единый механизм 910/990 и документационные правила 000.

## Что проверить до реализации

- Совместимость версии Immich с разделением работников между двумя узлами, общими путями и доступом по сети.
- Работа Docker в LXC, права к файлам и обмен медиаданными через Windows/WSL2.
- Память и свободное место существующего PVE.
- Перенос фотоархива на NAS при его появлении и неизменность путей.
- Допустимый механизм записи результатов Qwen в доступный пользователю поиск.
- План резервного копирования и тест восстановления PostgreSQL.

Это утверждение архитектуры, а не запись о выполненном развёртывании.
