# Подготовка развёртывания 430

## Требуемое состояние

Создать LXC 430 обычным механизмом гостевого контура на основе `guest.yaml`. Профиль `debian-lxc-docker` предусматривает вложенную контейнерную среду.

Перед запуском Immich **обязательно** подготовить внешний каталог PVE и смонтировать его в LXC как `/srv/photo-archive`. Наличие каталога в госте само по себе недостаточно: требуется проверка, что это именно отдельное постоянное подключение. Исходные снимки доступны Immich только для чтения; служебные данные `/srv/photo-archive/immich` должны быть доступны для записи. Каталог PostgreSQL `/var/lib/photo-archive/postgres` размещается на локальной Linux-файловой системе.

Адрес интерфейса определяется общей адресацией гостей проекта. Пользовательский порт Immich: 2283.

## Ограничения текущей подготовки

Машинные требования заданы в `guest.yaml` и `provision.yaml`, но **специализированная Ansible-роль развёртывания Photo Archive пока не реализована**. Общий playbook выполняет только базовую настройку Linux и Docker для этого гостя. До её появления команда развёртывания не создаст Immich, PostgreSQL или Redis.

Перед реализацией Ansible-роли необходимо:
- выбрать и закрепить совместимые неизменяемые версии образов Immich и PostgreSQL/VectorChord;
- определить и реализовать безопасную выдачу пароля PostgreSQL из OpenBao;
- обеспечить проверку фактической точки монтирования и права каталогов с отказом при отсутствии;
- подготовить Compose без публичного доступа к PostgreSQL/Redis, только с `IMMICH_WORKERS_INCLUDE=api`;
- согласовать сетевой доступ Windows к общей очереди, базе и медиаданным **без публикации этих служб в интернет**; до этой настройки удалённый работник не подключится;
- предусмотреть первый запуск сервера без Windows и последующую настройку внешней библиотеки;
- установить и проверить резервирование базы, затем проверить восстановление.

Предварительный лимит памяти LXC — 4 ГБ для первого запуска без машинного обучения. Это проверяемая гипотеза, а не гарантированное потребление. При необходимости увеличить память после измерений.

## Проверки при вводе

Сначала испытать 100–200 фотографий, затем подтвердить доступ по API и просмотр, запуск и перезапуск PostgreSQL, Redis, создание индексов, сетевой доступ с Windows, остановку фонового работника без потери галереи, реальное потребление памяти и процесс обновления.
