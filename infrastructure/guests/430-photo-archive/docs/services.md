# Службы и устройство 430

## Назначение и размещение

430 — LXC Debian с постоянно доступным веб-интерфейсом Immich. Исходные снимки остаются неизменными, каталогизация выполняется в базе.

| Место | Состав | Ответственность |
| --- | --- | --- |
| LXC 430, Proxmox | Immich с работником `api`, PostgreSQL с требуемым векторным расширением, Redis | Просмотр, API, каталог, альбомы, поиск по ранее построенным индексам |
| Основной компьютер Windows | Второй экземпляр `immich-server` без `api`, `immich-machine-learning`, LM Studio с Qwen3.8-27B | Фоновые задачи, распознавание и глубокое описание |
| Proxmox | Постоянное файловое хранилище | Оригиналы, миниатюры и служебные медиаданные |
| Windows | Яндекс Диск и средство односторонней передачи | Приём фотографий из облака, независимая локальная копия |

Два экземпляра `immich-server` образуют **одну установку**. У них должны совпадать версии, настройки доступа к PostgreSQL/Redis и внутренние пути к общим файлам. Только экземпляр на 430 обслуживает пользовательские API-запросы. Применение разделения работников настраивается средствами Immich; точные переменные сверяются с документацией закреплённой версии перед внедрением. Не допускаются два независимых сервера, изменяющих одну базу без согласованной конфигурации.

При выключенном Windows доступна существующая галерея и индексированный поиск. Обработка новых файлов и часть фоновых задач ожидают возвращения работников; отказавшие задания подлежат проверке и при необходимости повторному запуску.

## Ресурсы и ограничения

Предварительная опытная конфигурация LXC: 2 vCPU, 2 ГБ ОЗУ, системный диск 8–16 ГБ. Это **не подтверждённая производственная норма**: официальные рекомендации Immich для полного развёртывания выше. Потребление памяти и устойчивость проверяются на тестовой библиотеке, затем лимиты корректируются. Суммарные ресурсы PVE не должны мешать 100 и 910.

Использование Docker внутри LXC допускается в рамках проекта только после испытаний; это менее поддерживаемый Immich способ по сравнению с VM. Перед внедрением проверить nesting, права томов, работу Docker, обновления и восстановление LXC. При несовместимости вернуться к выбору VM без изменения роли 430.

PostgreSQL обязателен для Immich; SQLite не поддерживается в качестве его замены. Данные PostgreSQL держать на локальном подходящем хранилище LXC, не на SMB. Redis обслуживает общую очередь. Доступ к PostgreSQL и Redis извне ограничен адресом доверенного Windows-работника; запрещена публикация в интернет.

## Обработка и поиск

Специализированная служба Immich ML на Windows обрабатывает изображения для поиска и лиц. Второй `immich-server` выполняет задания, включая формирование миниатюр и извлечение метаданных. На Windows эти службы запускаются последовательно либо с ограничением ресурсов, чтобы не конфликтовать за видеопамять.

Qwen через LM Studio создаёт короткие описания, метки и предложения о качестве. Результаты сохраняются отдельно с идентификатором файла, версией модели и временем анализа. Интеграцию с Immich выполнять только через поддерживаемый API или штатный механизм метаданных, без прямого изменения его таблиц. До доказанной интеграции описания Qwen **не считаются доступными в поиске Immich**.

Никаких автоматических удалений, перемещений и изменения оригиналов по выводам моделей.
