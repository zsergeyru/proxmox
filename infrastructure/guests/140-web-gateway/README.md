# 140 — веб-шлюз

**Тип:** LXC  
**ОС:** Debian 13  
**Назначение:** единая точка входа в домашние веб-службы с HTTPS, общей авторизацией и домашней страницей.

Гость 140 не маршрутизирует обычный трафик домашней сети и не выполняет функции DHCP, DNS или VPN. Эти задачи остаются у сетевого шлюза 109. При остановке 140 обычный Интернет и внутренняя сеть должны продолжать работать.

Внутри 140 размещаются готовые службы:

- **Caddy** — обратный прокси и автоматическое получение HTTPS-сертификатов;
- **Authelia** — общий вход, второй фактор и группы доступа;
- **Homarr** — домашняя страница со ссылками на разрешённые приложения;
- **SQLite** — постоянное состояние Authelia, без отдельного сервера баз данных.

Планируемый CTID — **140**. Адрес по правилу проекта — `192.168.1.40`. Начальный ориентир ресурсов: 2 виртуальных процессора, 1 ГиБ ОЗУ и 16 ГиБ диска; после проверки нагрузки память можно увеличить. Исполняемые значения должны быть закреплены в `guest.yaml` и `provision.yaml` при реализации.

Доступ извне предполагается через Keenetic с динамическим публичным IPv4. Имена `*.zsergey.ru` используются для опубликованных приложений. Сам Immich, Home Assistant и другие приложения остаются в своих гостях.
