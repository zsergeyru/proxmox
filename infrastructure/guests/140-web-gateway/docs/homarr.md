# Прежняя домашняя страница Homarr

**Тип:** справка о прежнем решении  
**Статус:** не используется после перехода на собственные страницы.

Ранее на госте 140 был установлен Homarr 2.5.2. Его доски, виджеты и база сохраняются на постоянном томе в `/var/lib/web-gateway/homarr/` для возможного отката. Новая роль Ansible не запускает Homarr и не изменяет его сохранённые данные. Автоматически удалять их нельзя.

Текущая спецификация: [portal.md](portal.md). Разграничение прав и административные действия: [administration.md](administration.md). Порядок замены с сохранением старого состояния: [operations.md](operations.md).
