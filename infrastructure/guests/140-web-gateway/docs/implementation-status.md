## 1. Принято

- Отдельный LXC 140 — `web-gateway`, Debian 13, адрес по VMID `192.168.1.40`.
- Caddy, Authelia и Homarr; для Authelia — SQLite.
- Около 3–4 пользователей и группы `admins`, `family`, `guests`.
- Единый вход с паролем и вторым фактором; OIDC для совместимых приложений.
- Несекретная конфигурация в Git; хеши Argon2id и секреты OIDC в OpenBao; рабочие локальные файлы 140 с ограниченными правами.
- Постоянные данные Authelia/2FA, Homarr и Caddy с резервным копированием.
- Доступ по поддоменам `zsergey.ru` через прямой публичный IPv4 Keenetic с KeenDNS.
- Отсутствие зависимости сетевых функций 109 от состояния веб-служб 140.

## 2. Подготовлено

Есть локальный паспорт гостя, оглавление, спецификации Caddy, Authelia и Homarr, инструкция развёртывания, документ решений. Эти документы описывают целевое состояние и **не подтверждают** существование LXC в Proxmox.

## 3. Осталось реализовать

1. Создать машинные описания `guest.yaml`, `provision.yaml` и при необходимости `status.yaml`.
2. Закрепить версии образов, точные тома и порты в машинной конфигурации.
3. Реализовать повторяемое развёртывание через общую автоматизацию проекта.
4. Подготовить выдачу секретов из OpenBao и локальный файл пользователей.
5. Развернуть и проверить Caddy, Authelia, Homarr и постоянное состояние SQLite.
6. Подготовить DNS-записи Beget, перенаправление портов Keenetic и локальное разрешение имён.
7. По одному подключить Immich и Open WebUI к OIDC, отдельно определить поддержку Home Assistant.
8. Проверить ограничения групп, 2FA, работу мобильного Immich и резервное восстановление.
9. Измерить потребление ресурсов 140 и уточнить выделенную память.

## 4. Признаки готовности

Работа считается завершённой только после успешных проверок из [operations.md](operations.md): внешний HTTPS, второй фактор, запреты групп, мобильный Immich, сохранение постоянного состояния, восстановление из резервной копии и отсутствие воздействия на домашнюю сеть при остановке 140.
