# Состояние реализации 140

**Тип:** состояние реализации  
**Статус:** новая схема подготовлена в `feature/140-simple-web-portal`; испытания на работающем LXC 140 ещё не выполнены.

## 1. Подтверждённое прежнее состояние

На действующем LXC ранее были установлены Caddy, Authelia и Homarr; пользователь подтвердил вход через Authelia с Google Authenticator. Папка данных 140 находится на постоянном `mp0`. Прежняя административная доска Homarr по прямой ссылке не находилась, поэтому от неё решено отказаться.

## 2. Новая схема в коде

- Caddy и Authelia остаются готовыми компонентами, Homarr исключён из запуска Docker.
- Домашняя страница `https://home.zsergey.ru/` защищена паролем и вторым фактором Authelia.
- `/admin` и `/api/admin/*` доступны только из доверенной сети/VPN и группе `admins`. В Authelia есть явный запрет для остальных групп перед общим правилом.
- Статические HTML, CSS и JavaScript воспроизводятся из Git при `deploy 140`; закрытый системный обработчик обращается к существующему интерфейсу управления по Unix-сокету и не выдаёт ключи браузеру.
- Домашние ссылки формируются из включённых маршрутов. Администрирование содержит пользователей Authelia, домены Caddy и каталог гостей Proxmox только для чтения.
- Развёртывание переносит только старые назначения Homarr двух известных доменов, не меняя пароль, второй фактор, остальные маршруты, сертификаты, данные 340 и сохранённую базу Homarr.
- Изменяющие действия с гостями Proxmox намеренно отсутствуют до отдельной проверки безопасности через 910.

## 3. Что необходимо проверить на PVE

1. Согласованность конфигурации Docker и проверку Caddyfile после слияния.
2. Вход пользователя через Authelia, обязательный второй фактор и отсутствие прямого доступа к административным файлам.
3. Отказ для `family`/`guests` в `/admin` и `/api/admin/*`.
4. Отказ администратору из внешнего Интернета; адрес NAT должен соответствовать реальному внешнему источнику.
5. Создание испытательного пользователя, смену группы и включение/отключение пробного домена.
6. Сохранение учётных записей, TOTP, маршрутов и прежней базы Homarr после повторного `deploy 140`.
7. Мобильный Immich, Home Assistant и Open WebUI подключать отдельно после проверки их собственного входа.
8. Резервирование и восстановление проверять отдельно, когда будут готовы SMB и USB.

Работающую систему не следует считать обновлённой до настоящего `infra-manager deploy 140`. Код и автоматические проверки в GitHub не заменяют приёмку на реальном PVE.
