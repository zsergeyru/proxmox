# Каталог гостей на административной странице

**Тип:** локальная спецификация службы
**Статус:** каталог сформирован из Git; работа нового интерфейса на PVE ещё не проверена.

## 1. Назначение

На `https://home.zsergey.ru/admin` администратор видит список гостей Proxmox: номер, имя и объявленные в Git службы. Это не состояние живого PVE. Нельзя показывать «работает» без проверки самого гостя.

Обычный пользователь не получает список гостей и не может открыть административную страницу. Весь `/api/admin/*` ограничен Caddy по исходному IP, Authelia — по группе `admins` и второму фактору.

## 2. Источник и обновление

Штатный механизм `infra-manager homarr-catalog` на 910 исторически имеет такое имя, но не зависит от запущенного Homarr. Он формирует каталог из описаний Git без доступа к закрытым ключам PVE. Результат сохраняется в госте 140 как `/var/lib/web-gateway/management/catalog/guests.json`.

Закрытая служба страниц читает этот файл и выдаёт только имя и номер гостя по `/api/admin/guests`. Добавление гостя в Git и последующий `infra-manager sync 140` обновляют список без перезапуска Caddy и без изменения 140.

## 3. Действия над машинами

Кнопки `deploy`, `repair`, `sync`, `start` и `stop` в новом интерфейсе **не реализованы**. Они потребуют отдельного доверенного вызова из 140 в 910 с независимой проверкой полномочий, подтверждением и учётом задания. Секреты PVE, OpenBao и Docker-сокет не передаются браузеру.

Приёмка: проверить доступ администратора и отказ для семейного пользователя и внешнего адреса, затем добавить испытательного гостя в Git и обновить `sync 140`.
