## 1. Назначение и версия

### 1.1. Роль

Home Assistant умеет работать с голосовыми службами через протокол Wyoming.

Speaches предоставляет OpenAI-совместимый API.

Wyoming OpenAI является готовым преобразователем между этими двумя интерфейсами:

```text
Home Assistant
↓ Wyoming
Wyoming OpenAI
↓ OpenAI-compatible API
Speaches
```

Собственный Wyoming-прокси для проекта не разрабатывается.

### 1.2. Образ

Фиксируется стабильный образ:

```text
ghcr.io/roryeckel/wyoming_openai:0.5.0
```

Порт:

```text
10300/tcp
```

## 2. Связь с Speaches

### 2.1. Базовые параметры

Wyoming OpenAI работает в одной Docker-сети со Speaches.

Целевые значения:

```text
WYOMING_URI=tcp://0.0.0.0:10300

STT_OPENAI_URL=http://speaches:8000/v1
STT_BACKEND=SPEACHES
STT_MODELS=stt-default

TTS_OPENAI_URL=http://speaches:8000/v1
TTS_BACKEND=SPEACHES
TTS_MODELS=tts-default-ru
```

Язык первой конфигурации — русский.

Дополнительные языки добавляются после проверки, а не заранее.

### 2.2. VAD

Не следует одновременно включать несовместимые способы определения конца речи на нескольких уровнях.

При работе через Wyoming поведение VAD настраивается по рекомендациям Wyoming OpenAI/Speaches для выбранной версии и проверяется на реальном Home Assistant Assist.

## 3. Связь с Home Assistant

### 3.1. Подключение

Home Assistant подключается к:

```text
<адрес 420>:10300
```

через штатную интеграцию Wyoming.

После обнаружения службы должны быть доступны STT и TTS, которые фактически выполняются Speaches.

### 3.2. Граница ответственности

Wyoming OpenAI:

- не хранит историю диалогов;
- не является голосовым агентом;
- не выбирает действия Home Assistant;
- не запускает собственную модель речи.

Его задача только преобразовать Wyoming-запрос в совместимый запрос к готовому backend.

## 4. Данные и безопасность

### 4.1. Постоянное состояние

Wyoming OpenAI считается практически без состояния.

Его настройки воспроизводятся из машинной конфигурации.

Отдельный каталог постоянных данных для него в базовой реализации не требуется.

### 4.2. Доступ

Порт `10300` доступен только Home Assistant и явно разрешённым голосовым клиентам.

Он не публикуется в Интернет.

Если в будущем появится несколько Home Assistant или отдельные голосовые панели, доступ расширяется через общий контракт безопасности проекта.

## 5. Развёртывание и проверка

### 5.1. Порядок запуска

Wyoming OpenAI запускается после готовности Speaches.

Compose должен выражать эту зависимость через проверку готовности Speaches, а не только через порядок запуска контейнеров.

### 5.2. Проверка

После запуска проверяется:

1. порт `10300` принимает TCP-соединение;
2. Home Assistant обнаруживает/подключает Wyoming-службу;
3. STT-запрос из Home Assistant доходит до Speaches;
4. TTS-запрос из Home Assistant доходит до Speaches;
5. после перезапуска 420 ручная перенастройка Home Assistant не требуется.

Ошибки Speaches должны быть видны в журналах Wyoming OpenAI и не маскироваться собственными заглушками.
