## 1. Что реализовано

### 1.1. Гость и Docker

В проекте уже есть:

- `guest.yaml` для LXC 420;
- профиль `debian-lxc-docker`;
- 2 CPU, 4 ГБ RAM, 1 ГБ swap, диск 32 ГБ;
- вычисляемый административный адрес по общему правилу VMID: `192.168.4.20`;
- `provision.yaml` для Debian 13 amd64;
- установка Docker через общую роль.

### 1.2. Speaches

Автоматизация фиксирует:

- `ghcr.io/speaches-ai/speaches:0.8.3-cpu`;
- порт `8000`;
- STT `Systran/faster-whisper-small`;
- TTS `speaches-ai/piper-ru_RU-irina-medium`;
- логические имена `stt-default` и `tts-default-ru`;
- отдельный воспроизводимый `model_aliases.json`;
- кэш Hugging Face в `/var/cache/ai-services/speaches/huggingface`.

Ansible запускает Speaches, ждёт `/health`, затем скачивает обе модели через штатный `POST /v1/models/{model_id}`.

### 1.3. Wyoming OpenAI

Автоматизация фиксирует:

- `ghcr.io/roryeckel/wyoming_openai:0.5.0`;
- порт `10300`;
- язык `ru`;
- STT/TTS backend `SPEACHES`;
- обращение к Speaches внутри Compose-сети по `http://speaches:8000/v1`.

Wyoming OpenAI запускается только после успешной проверки готовности Speaches.

### 1.4. Повторяемость и проверки

Есть специализированная роль Ansible `ai_services` и контрактный тест.

Роль:

- создаёт каталоги;
- формирует конфигурацию и Compose;
- проверяет Compose;
- получает закреплённые образы;
- запускает Speaches;
- загружает модели;
- запускает Wyoming OpenAI;
- проверяет порт Wyoming;
- проверяет, что обе модели присутствуют в Speaches.

## 2. Что ещё нужно проверить

### 2.1. На реальном PVE

Нужно выполнить фактический `Deploy Guest 420` и подтвердить:

- создание LXC;
- работу Docker внутри LXC;
- успешную загрузку образов;
- загрузку обеих моделей;
- повторный прогон без лишних изменений.

### 2.2. Голос

Нужно проверить на реальных русских примерах:

- точность `faster-whisper-small`;
- задержку короткой команды;
- задержку записи 10–20 секунд;
- качество Piper Irina;
- потребление CPU и RAM на N150.

### 2.3. Потребители

После проверки самой 420 нужно подключить:

- Home Assistant → Wyoming OpenAI;
- Open WebUI → Speaches;
- Hermes → Speaches.

Сетевые соединения должны быть разрешены только нужным внутренним потребителям. Текущий `access.yaml` не является описанием обычных TCP/HTTP правил и поэтому не расширяется искусственно для этих портов.

## 3. Переход со старой схемы

### 3.1. Старый 331

Старый каталог:

```text
infrastructure/guests/331-ai-services/
```

остаётся переходным только до фактической проверки 420.

После успешного развёртывания 420 нужно:

1. убедиться, что VM/LXC 331 фактически не используется;
2. перенести оставшиеся ссылки на 420;
3. удалить устаревший каталог 331 отдельным изменением.

## 4. Критерий завершения

420 считается полностью завершённым, когда:

- `Deploy Guest 420` проходит на PVE;
- повторный прогон идемпотентен;
- русский STT и TTS проверены;
- Home Assistant использует Wyoming OpenAI;
- 410 использует Speaches;
- производительность N150 признана достаточной либо ресурсы/модель скорректированы;
- старый 331 удалён как устаревший.
