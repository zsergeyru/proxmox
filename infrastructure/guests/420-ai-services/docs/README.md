# Документация 420 ai-services

Этот каталог описывает целевое состояние гостя `420 ai-services` изнутри.

420 содержит только готовые общие AI-службы. Если нужную функцию уже предоставляет подходящий готовый проект, собственный сервис для неё не создаётся.

## Порядок реализации

После принятия документации:

1. создать машинное описание `420-ai-services`;
2. подготовить Debian LXC с Docker;
3. реализовать общую Ansible-роль или подходящий повторяемый механизм;
4. развернуть Speaches;
5. проверить STT и TTS;
6. развернуть Wyoming OpenAI;
7. подключить Home Assistant;
8. подключить 410/Open WebUI к Speaches;
9. выполнить замеры скорости и качества;
10. после успешной проверки вывести старый `331-ai-services` из проекта.
