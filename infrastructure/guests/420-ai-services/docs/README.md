# Документация 420 ai-services

Этот каталог описывает целевое состояние гостя `420 ai-services` изнутри.

420 содержит только готовые общие AI-службы. Если нужную функцию уже предоставляет подходящий готовый проект, собственный сервис для неё не создаётся.

## Порядок проверки

Реализация в Git уже подготовлена. Следующий порядок:

1. выполнить `Deploy Guest 420`;
2. убедиться, что Docker, Speaches и Wyoming OpenAI запущены;
3. проверить загрузку обеих моделей;
4. выполнить русский STT и TTS;
5. выполнить повторный `Deploy Guest 420` и проверить идемпотентность;
6. подключить Home Assistant;
7. подключить 410/Open WebUI к Speaches;
8. выполнить замеры скорости и качества на N150;
9. после успешной фактической проверки вывести старый `331-ai-services` из проекта.
