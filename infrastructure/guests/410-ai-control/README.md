# 410 ai-control

`410 ai-control` — центральная VM интеллектуального управляющего контура квартиры.

Она предоставляет рабочую среду одного основного универсального AI-агента, Open WebUI как обязательный веб-интерфейс, подключение локальных и внешних AI-моделей и доступ к разрешённым инструментам квартиры.

410 не заменяет Home Assistant, сеть, мониторинг или инфраструктурный исполнитель. Он связывает пользовательские задачи с профильными системами и проверяет результат.

## Паспорт

```text
VMID:          410
name:          ai-control
тип:           VM
профиль:       debian-vm
CPU:           2
RAM:           4096 MB
диск:          24 GB
managed pool:  нет
```

`pve_management: false` задан специально: 410 не должен через обычный управляемый контур изменять жизненный цикл собственной VM.

## Основная роль

410 должен обеспечивать:

- Open WebUI для пользователя;
- одного основного универсального агента;
- заменяемость агента;
- локальные и внешние AI-модели;
- общие инструменты Home Assistant, инфраструктуры, сети, мониторинга, Git и других сервисов;
- память, задачи, события, расписание и уведомления;
- передачу повторяемых инфраструктурных изменений в `910 infra-manager`.

Текущий основной агент — Hermes.

## Границы

410 не является:

- хостом Home Assistant;
- инфраструктурным исполнителем OpenTofu/Ansible/Packer;
- сервером DNS/VPN;
- NVR;
- общим файловым хранилищем;
- обязательным местом размещения локальной AI-модели.

Остановка 410 не должна останавливать базовую работу квартиры и самостоятельных сервисов.
