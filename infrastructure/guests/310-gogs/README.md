# 310 Gogs

Отдельный LXC с личным Git-сервером. Исходная система работает в Docker
Desktop на Windows; перенос выполняется с сохранением SQLite, репозиториев,
пользователей и секретов.

| Источник | Назначение |
|---|---|
| `guest.yaml` | LXC 310, защита и разрешённое пересоздание отсутствующего гостя |
| `provision.yaml` | Docker, закреплённый образ, отдельный том 30 ГиБ |
| `status.yaml` | Рабочий Gogs, порты и постоянные данные |
| `../../security/access.yaml` | Права машин на управление гостями |
| `docs/migration.md` | Перенос с Docker Desktop и первое включение |
| `docs/recovery.md` | Повторное развёртывание и аварийное восстановление |

Управление: `infra-manager deploy 310` с PVE (через единый механизм
OpenTofu, подготовки тома и Ansible). Служба **не запускается**, пока
администратор не подтвердил перенос полноценного каталога `/data`.
После первичного переноса повторный `deploy` сохраняет пользователей,
базу, репозитории и закрытые ключи.

Внешний Git по HTTPS: `https://git.zsergey.ru/` через Caddy 140;
домен включается через действующую административную страницу Caddy,
**после** проверки миграции. Git SSH: порт 2222 только внутри домашней
сети; отдельный порт на Keenetic не открывать.

Gogs не является источником собственного развёртывания: файлы проекта
и аварийный read-only доступ Infra Manager остаются в GitHub.
