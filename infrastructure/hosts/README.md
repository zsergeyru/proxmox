# Физические машины проекта

Здесь находятся **описания физических машин**, а не сценарии их установки.

| Каталог | Назначение |
|---|---|
| [`pve/`](pve/) | Хост Proxmox, его сеть, хранилища и наблюдаемое состояние |
| [`nas/`](nas/) | Физический NAS, SSH-доступ, настройки OMV и права |

Для каждой физической машины предусматривается собственный `storage.yaml` единого формата. Общая схема находится в [`../schemas/physical-storage.schema.yaml`](../schemas/physical-storage.schema.yaml). Перенос действующих дисков в этот формат выполняется отдельно от утверждения схемы.

**Граница каталогов:** `infrastructure/hosts/` хранит машинные описания, документацию и настройки. Исполняемые программы размещаются в `scripts/`, а сценарии применения настроек Ansible — в `automation/`. Например, программа резервирования состояния гостя 140 находится в [`../../scripts/backup/backup-140.py`](../../scripts/backup/backup-140.py), не внутри описания PVE.

Корневые файловые системы гостей и данные служб сюда не относятся. Для них используются `infrastructure/guests/` и постоянные хранилища, описанные в разделе [хранения](../../docs/600-storage/620-storage-layout.md).
