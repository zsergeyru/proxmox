# NAS — физический сервер хранения

**Тип:** самостоятельный физический сервер, не гость Proxmox.
**ОС:** Debian 13 с OpenMediaVault 8; первоначальная установка вручную на системный SSD.
**Управление:** оператор запускает `infra-manager` на PVE; 910 управляет физическим NAS по SSH через Ansible. Изменения дисков разрешены только по отдельно подтверждённому плану.

## Назначение

NAS предоставляет домашним компьютерам общие файлы, хранит основные данные и отдельные резервные копии. При отключении Proxmox и Infra Manager сервер продолжает обслуживать пользователей самостоятельно.

## Оборудование

- Плата MSI A78M-E45, процессор AMD Athlon X4 760K.
- Оперативная память 8 ГБ DDR3 (2 × 4 ГБ); проверена 18 проходами Memtest86+ без ошибок.
- Системный SSD SPCC 120 ГБ.
- HDD Seagate ST1000DM003 1 ТБ.
- Два HDD Seagate SkyHawk ST4000VX016 по 4 ТБ.

Эти сведения описывают выбранную комплектацию; при замене диска его роль определяют по устойчивому идентификатору, а не по `/dev/sdX`.
