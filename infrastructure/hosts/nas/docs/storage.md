## 1. Состав хранилищ

| Накопитель | Назначение | Файловая система |
| --- | --- | --- |
| SPCC SSD 120 ГБ | Debian 13, OpenMediaVault 8 | ext4 |
| Seagate ST1000DM003 1 ТБ | Общие, временные файлы, фильмы, торренты; без резервирования | ext4 |
| SkyHawk ST4000VX016 4 ТБ №1 | Основные данные | Отдельный однодисковый пул ZFS |
| SkyHawk ST4000VX016 4 ТБ №2 | Резервные копии основных данных | Отдельный однодисковый пул ZFS |

Два диска по 4 ТБ **не объединяются в зеркало**. Второй пул предназначен для управляемых резервных копий. Раздельные пулы на двух дисках одного сервера не защищают от общей аварии сервера, кражи или пожара.

Терабайтный диск хранит данные, потеря которых допустима. Он не должен участвовать в обязательном резервном копировании. Дедупликация ZFS не используется.

## 2. Граница управления

### Оператор и OpenMediaVault

Только оператор через средства OpenMediaVault выполняет:

- выбор накопителя по модели, серийному номеру и устойчивому идентификатору;
- очистку, разметку, создание и удаление файловых систем;
- создание и удаление пулов ZFS;
- подключение файловых систем, изменение состава и устройства хранения.

Задания Infra Manager не форматируют диски, не изменяют разделы и не создают, не уничтожают и не импортируют пулы автоматически.

### Infra Manager

Infra Manager через SSH и Ansible:

- проверяет наличие и тип требуемых подключённых файловых систем;
- создаёт отсутствующие служебные каталоги, не удаляя содержимое существующих;
- назначает владельцев и права только на разрешённые каталоги;
- настраивает службы, общие папки и задания резервирования;
- получает состояние SMART, ZFS и свободное место только для диагностики.

Управление выполняется на физическом NAS, не через механизм создания гостей PVE.

## 3. Каталоги и безопасное применение

### Структура тома 1 ТБ

```text
downloads/
  incomplete/
  complete/
movies/
music/
shared/
temporary/
```

Это логическая структура относительно точки подключения файловой системы. Абсолютный путь задаётся после определения её постоянного подключения средствами OMV; нельзя выбирать путь по текущему имени `/dev/sdb`.

### Обязательная защита данных

Перед созданием **любого** каталога Infra Manager обязан проверить, что:

1. Ожидаемый том действительно подключён, а путь находится на нём, не на корневом SSD.
2. Идентификатор файловой системы совпадает с явно разрешённым в настройках NAS.
3. Подключение доступно на запись в допустимой области.

При отсутствии диска, неправильном подключении, несовпадении идентификатора или ошибке проверки задание завершает работу **без создания папок**. Оно не удаляет пользовательские данные и не исправляет несовпадение форматированием. Для двух пулов ZFS действует тот же запрет.

Каталоги, которые случайно удалены, воссоздаются без попытки автоматически восстанавливать или удалять их прежнее содержимое.
