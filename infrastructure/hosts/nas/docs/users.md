## 1. Общие пользователи

Единственный перечень первоначальных пользователей и групп всего проекта находится в [infrastructure/users.yaml](../../../users.yaml). Отдельных списков пользователей внутри описаний NAS и других приложений нет.

Группы первого этапа: `admins`, `family`, `guests`. Имена пользователей должны быть согласованы отдельно. Служебный администратор Authelia `admin` в общий перечень не включается: его учётную запись создаёт гостевой установщик.

Общий каталог не является сервером авторизации. NAS использует собственные локальные записи Linux/Samba и отдельные пароли. Authelia использует собственную постоянную базу и второй фактор. LDAP не применяется.

## 2. Права на папки

Права NAS находятся только в [../access.yaml](../access.yaml). Этот файл описывает чтение и запись групп из общего каталога для `shared`, `movies`, `music`, `data`.

Пример назначения **не применяется**, пока не согласованы права:

```yaml
shares:
  shared:
    read_groups: [family]
    write_groups: [admins]
  movies:
    read_groups: [family]
    write_groups: [admins]
  music:
    read_groups: [family]
    write_groups: [admins]
  data:
    read_groups: []
    write_groups: [admins]
```

`write_groups` подразумевает чтение и запись, `read_groups` — только чтение. Пустые списки не выдают разрешений. Пример не вводить в действующую конфигурацию без подтверждения.

Права Samba должны соответствовать правам файловой системы; разрешения нельзя обеспечивать только одной стороной. Гостевой доступ запрещён.

## 3. Развёртывание и сохранность

При проверке проекта Infra Manager объединяет каталог людей из `infrastructure/users.yaml` и права NAS из `infrastructure/hosts/nas/access.yaml`. Проверяются повторы, системные имена, неизвестные группы и попытки записать пароль или хеш в Git.

Для первоначального развёртывания NAS следует реализовать создание отсутствующих локальных пользователей, назначение паролей Samba через отдельный закрытый механизм и применение указанных прав. **Этот исполнитель пока не подключён к `deploy nas`**. Само наличие двух файлов не создаёт ни одной учётной записи.

Пароли SMB хранятся независимо от Authelia. Их выдачу через OpenBao ещё необходимо реализовать; хеши Authelia использовать нельзя. Права и данные существующих пользователей при повторном `deploy` не удаляются и не сбрасываются из Git.

Общая папка `data` остаётся одной; разделять её на другие папки пока не требуется.
