## 1. Учётные записи

Машинный список находится в [../users.yaml](../users.yaml). Он содержит имена пользователей и их членство в группах, но не содержит паролей, хешей, токенов или временных кодов.

Authelia не используется для входа в SMB. Одинаковые имена пользователей Authelia и NAS допустимы, однако это отдельные учётные записи. LDAP и контроллер домена не нужны.

Пример заполнения (имена только для пояснения, не являются настоящими пользователями):

```yaml
groups:
  - nas-family
  - nas-managers

users:
  - name: exampleuser
    groups: [nas-family]
  - name: examplemanager
    groups: [nas-family, nas-managers]
```

Использовать только имена из согласованного списка. Имя существующей служебной записи NAS нельзя автоматически захватывать или менять.

## 2. Права на папки

В том же `users.yaml` определяются разрешения для `shared`, `movies`, `music` и `data`:

```yaml
shares:
  shared:
    read_groups: []
    write_groups: [nas-family]
  movies:
    read_groups: [nas-family]
    write_groups: [nas-managers]
  music:
    read_groups: [nas-family]
    write_groups: [nas-managers]
  data:
    read_groups: []
    write_groups: [nas-managers]
```

Значения выше — **пример**, а не принятое распределение прав. `read_groups` даёт чтение; `write_groups` даёт чтение и запись. Пустые списки никому не предоставляют соответствующее право. Гостевой вход для всех этих папок отключён.

Права SMB и права каталогов на файловой системе должны совпадать по смыслу: недостаточно разрешить запись только в Samba, если файловая система её запрещает.

## 3. Первоначальное развёртывание

До первого `infra-manager deploy nas` оператор определяет пользователей, группы и разрешения в `users.yaml`. Репозиторий проверяет формат, повторения имён, системные имена, несуществующие группы и попытки записать пароль в конфигурацию.

При развёртывании Infra Manager должен создать отсутствующие локальные записи Linux и Samba, выдать им права и повторно применить изменения без удаления пользовательских данных. Отсутствие имени в новой версии `users.yaml` **не является приказом удалить существующую учётную запись**.

Пароли для SMB должны выдаваться и храниться отдельно в OpenBao. Их нельзя извлекать из хешей Authelia или помещать в Git. Первоначальная выдача паролей и применение пользователей к OMV пока не реализованы и должны быть завершены до полноценного развёртывания NAS.

Сейчас `users.yaml` создан с пустыми списками: до согласования реальных пользователей и прав настройку учётных записей нельзя считать завершённой.
