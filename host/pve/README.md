# Proxmox-хост: `pve`

Этот каталог относится только к конфигурации самого гипервизора.

Прикладные сервисы непосредственно на Proxmox-хост не устанавливать. Home Assistant, DNS/VPN, AI, мониторинг, Frigate и обычные Docker-приложения должны жить в VM/LXC.

## Фактическое состояние

Снимок состояния снят с работающего сервера 2026-09-12.

Proxmox VE: 9.2.18

### Текущие реальные гостевые системы

На хосте фактически существуют две VM:

```text
100  HAOS      running
320  ai-agent  running
```

Состояние `running` оставлено как фактическое значение Proxmox.

LXC-контейнеров на момент снимка нет.

VM `100` описывается в [`../../guests/100-haos/`](../../guests/100-haos/) и является текущей рабочей системой Home Assistant. Исторический VMID сохраняется; отдельная миграция на `201` потребуется только при появлении практической причины.

VM `320` соответствует временному каталогу [`../../guests/320-ai-control/`](../../guests/320-ai-control/). Имя объекта в Proxmox сейчас `ai-agent`, хотя архитектурное имя каталога — `ai-control`.

## Структура каталога хоста

- [`network/`](network/) — фактическая сеть хоста и сетевой мост;
- [`storage/`](storage/) — хранилища, LVM и точки монтирования;
- [`backup/`](backup/) — текущее хранилище резервных копий и открытые вопросы;
- общая целевая архитектура сети находится в [`../../docs/40-network.md`](../../docs/40-network.md).

## Принцип

Здесь фиксируется наблюдаемое состояние самого PVE-хоста. Требуемые параметры VM/LXC принадлежат их каталогам `guests/`, а управляемые прикладные конфигурации внутри гостевых систем — их `rootfs/`.
